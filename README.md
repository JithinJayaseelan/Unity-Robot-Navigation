# Unity-Robot-Navigation
A simple interactive 3D environment developed using Unity, featuring a robot with basic movement mechanics.

  🎮 Features

- Interactive 3D environment
- Robot walking
- Running
- Jumping
- Physics-based movement
- Environment created using Unity tools

  🛠️ Technologies Used

- Unity
- C#
- Unity Asset Store

  🎥 Demo

[Watch the Project Demo](./VID-20260602-WA0009.mp4)

  📌 Project Overview

This project demonstrates the development of a basic interactive environment in Unity and the implementation of robot movement mechanics.

The robot was integrated from the Unity Asset Store and programmed to move, walk, run, and jump across the environment.

  🚀 Learning Outcomes

- Unity environment creation
- Basic C# scripting
- Character movement
- Physics implementation
- Working with Unity assets
